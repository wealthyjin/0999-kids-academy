# 0.999 Kids Academy

A lightweight, mobile-first Chinese children's learning game. Static files only.

## Privacy
- No child name, photo, voice recording, or learning dossier is included in this repository.
- This static demo does not upload or store microphone audio.
- Browser speech recognition availability depends on browser support, HTTPS, network and device settings.
- Do not add API keys, child records, or private audio to this public repository.

## Deploy
GitHub Actions workflow: `.github/workflows/pages.yml`.
GitHub Pages source is configured to **GitHub Actions**.
Every push to `main` triggers deployment.

Expected URL: https://wealthyjin.github.io/0999-kids-academy/

## Scope
This is a static interactive prototype. Natural real-time AI tutoring and premium neural TTS require a separately secured backend; never place provider API keys in this public frontend.
